MapAgent: Indoor Localisation and Spatial Reasoning

A Qwen3-based localisation agent that selects candidate positions using BLE, motion and map evidence, with independent verification and deterministic fallback.

The research question

How can an indoor-localisation agent reason over ambiguous wireless observations while keeping its decisions within the constraints of a known map?

My contribution

  1. Developed the core localisation pipeline and its evaluation workflow as a final year project.
  2. Connected BLE observations, motion evidence and supplied map geometry with Qwen3-based candidate selection.
  3. Built a decision path with independent verification and deterministic fallback.
  4. Evaluated the system across six sites and 41 trajectories.

How it works

  1. 01Build a structured set of candidate positions from sensor observations and map constraints.
  2. 02Provide the agent with bounded evidence for selecting a candidate location.
  3. 03Check the proposed decision with an independent verifier.
  4. 04Return a deterministic fallback when the proposed decision does not pass verification.

Evaluation & findings

6Evaluation sites
41Trajectories
3.317 mTrajectory-averaged error

Across six sites and 41 trajectories, the verified agent obtained a trajectory-averaged localisation error of 3.317 m. The evaluation used supplied map geometry and anchor layouts.

Verification makes the decision process explicit, but valid reasoning does not guarantee the smallest location error. Evaluating the agent against deterministic choices is an essential part of the system design.
