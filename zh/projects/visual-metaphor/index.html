视觉隐喻与多模态推理

研究背景

视觉隐喻要求智能体将图像内容与未被直接陈述的含义联系起来。在交流游戏中，这一解释还受到队友及对手可能掌握的信息，以及当前交互目标的影响。

项目结合视觉语义基准 MetaVision-DB 与双模块视觉语言智能体框架 MACH，同时研究视觉证据的理解，以及交流策略条件下的表达生成。

研究问题

智能体如何理解间接的视觉含义、推断其他玩家掌握的信息，并选择符合交流策略的表达？

个人贡献

  • 主导 MetaVision-DB 数据构建，覆盖 800 张图像、四类视觉—语义关系和三种交流游戏。
  • 组织概念与图像对齐、结构校验及人工质量审查。
  • 共同开发 MACH，结合对比式视觉语义推理与策略条件下的隐喻生成。
  • 在明确的平民与卧底阵营配置下，对 MACH 开展 Visual Undercover 评测。

数据与研究设计

基准包含 800 张图像，覆盖四类视觉—语义关系及 Visual Undercover、Visual Taboo、Visual Dixit 三种交流游戏。数据构建包括概念与图像对齐、结构校验和人工质量审查。

97.2% 的结果来自基于 Gemini 3.1 Pro 的 Visual Undercover 实验：三名 MACH 平民智能体对阵两名 Raw-VLM 卧底智能体。该数值表示这一游戏与阵营配置下平民团队的胜率，并非通用图像理解准确率。

研究方法

  1. 01围绕三种游戏和四类视觉—语义关系组织概念与图像示例，使用一致的数据结构并开展人工审查。
  2. 02通过对比式视觉语义推理解释图像，结合游戏上下文比较候选含义。
  3. 03利用结构化记忆与隐喻理论知识，按交流策略生成隐喻表达。
  4. 04在评价候选表达和选择交流行动时，模拟队友与对手可能作出的响应。

实验与评估

800图像 · MetaVision-DB
3通信游戏
97.2%胜率 · 指定三对二设置

在使用 Gemini 3.1 Pro 的 Visual Undercover 实验中，三名 MACH 平民智能体对阵两名 Raw-VLM 卧底智能体，平民阵营胜率达到 97.2%。该结果对应这一具体游戏与阵营配置。

讨论

模型表现与具体交流目标、基础模型及阵营分配密切相关。解释游戏胜率时，需要同时考虑交互规则、实验配置与视觉语义数据的质量。
